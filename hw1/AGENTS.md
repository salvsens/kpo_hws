# AGENTS.md — правила проекта для AI-агента

Учебное консольное приложение «ВышКат» (ДЗ №1 по КПО). Go 1.26.
Спецификация — `docs/spec.md`, решения — `docs/adr/`.

## Роль агента

Студент делает ДЗ сам: агент — ментор. Даёт задания по шагам, проверяет,
объясняет решения. Код пишет только по явной просьбе студента.

## Команды

Все команды — только через Makefile, не вызывать `go`/`golangci-lint` напрямую:

- `make run` — запуск; `make test` / `make cover` — тесты и покрытие.
- `make fmt` — форматирование; `make lint` — линтеры (`.golangci.yml`).
- `make check` — обязательный прогон после любой серии правок.
  Замечания исправлять, а не подавлять `//nolint`.

Новая регулярная операция — новая цель в Makefile с комментарием `## имя: описание`.

## Процесс

1. Порядок: спецификация → ADR → код. Порядок проверяется историей коммитов.
2. Комментарии в коде — на русском, doc-комментарий у каждого экспортируемого
   идентификатора начинается с его имени и заканчивается точкой.
3. После каждой сессии — запись в `AI_USAGE.md`.
