# 0002. Структура пакетов

Дата: 2026-10-25

## Статус

Принято

## Контекст

Приложение — консольный учёт парка (спецификация, раздел 4). Требования:

- предметная область не выполняет ввод-вывод (спецификация, раздел 6);
- техосмотр (`ServiceCenter`) и правило «для новичков» заменяются без
  правки кода парка (FR-3, FR-7);
- зависимости собираются DI-контейнером в одной точке;
- структура не должна быть сложнее задачи: за overengineering снижают оценку.

## Решение

```
cmd/vyshkat/        точка входа: сборка зависимостей в контейнере dig и запуск REPL
internal/domain/    сущности и инварианты: Asset, Vehicle, EnergyConsumer и их типы (ADR-0001)
internal/fleet/     сервисный слой: парк, техосмотр, правило для новичков, выдача номеров, отчёты
internal/cli/       REPL: разбор команд, вывод, сценарий demo
```

Направление зависимостей — только сверху вниз:

```
cmd/vyshkat → cli → fleet → domain
```

- `domain` не импортирует другие пакеты проекта.
- `fleet` объявляет интерфейсы, которые потребляет сам: `ServiceCenter`
  (техосмотр) и правило отбора для новичков. Там же — реализации по
  умолчанию (лимит расхода 2.0 кВт·ч, простота ≥ 6). Тесты подменяют их
  фейком или моком.
- `cli` работает через `io.Reader`/`io.Writer`, поэтому тестируется без
  реальной консоли.
- Только `cmd/vyshkat` знает о контейнере (ADR-0003).

## Альтернативы

- Всё в одном пакете — отклонено: нельзя проверить, что домен не зависит
  от консоли, и границы модулей из ТЗ не видны.
- Отдельный пакет на каждую реализацию (`inspection/`, `policy/`,
  `report/`) — отклонено: по одному-два файла в пакете, лишние импорты,
  overengineering для трёх видов транспорта.
- Слои «чистой архитектуры» (`usecase/`, `repository/`, `adapter/`) —
  отклонено: нет хранилища и сети, слои были бы пустыми.

## Последствия

- Плюсы: границы проверяются компилятором — циклический импорт не
  соберётся; каждый пакет тестируется отдельно.
- Минусы/риски: `fleet` со временем может разрастись. Если появится склад
  запчастей или сотрудники (спецификация, раздел 2, «не входит»), это
  новые пакеты рядом с `fleet`, а не новые файлы в нём.
